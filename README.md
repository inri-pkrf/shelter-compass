# מצפן החלטות – מדיניות התגוננות (אפליקציית טוטם)

כלי חזותי ואינטראקטיבי לתמיכה בקבלת החלטות על מדיניות התגוננות, מותאם למסך טוטם מגע אנכי **1080×1920 (Full HD)**.

## הפעלה (React בלבד – Create React App)
```bash
npm install
npm start        # פותח http://localhost:3000
```
ל-AI: העתיקו `.env.example` ל-`.env` והדביקו `ANTHROPIC_API_KEY`. `npm start` מפעיל גם שרת קטן (פורט 8787) שמחזיק את המפתח.

## העלאה ל-GitHub Pages
1. צרו ריפו ב-GitHub וחברו אותו: `git init`, `git remote add origin <כתובת הריפו>`.
2. אם האתר יושב בכתובת `https://USER.github.io/REPO` אפשר להחליף ב-`package.json` את `"homepage": "."` בכתובת הזו.
3. `npm run deploy` – בונה ומעלה לענף `gh-pages`. ב-GitHub: Settings ‏→ Pages ‏→ Branch: `gh-pages`.

**חשוב:** GitHub Pages מגיש רק קבצים סטטיים, ולכן שם אין שרת וה-AI לא יעבוד – האפליקציה תפעל עם החישוב המקומי. כדי לקבל AI באתר המאוחסן יש להריץ את `server/index.cjs` באחסון אחר ולהגדיר `REACT_APP_API_URL` ב-`.env` לפני `npm run deploy`. אל תשימו מפתח API בקוד הצד-לקוח.

## זרימת המשתמש
1. **בחירת נתונים** – 32 שיקולים בארבע קטגוריות, מבוססים על שני המסמכים.
2. **דירוג קריטיות** – מדחום 1–5 לכל נתון.
3. **עיבוד נתונים** – Claude מקבל את הדירוגים וחישוב בסיס ומחזיר מד, המלצה לכל מגזר ופסקת הסבר.
4. **המלצה** – מד חצי-עיגול (ירוק = שגרה, אדום = התגוננות), ארבעה מגזרים, ופסקת "עיבוד נתונים".

## איך נקבע הציון (חשוב לכייל!)
- לכל שיקול ב-`src/data/factors.js` יש `lean` (כיוון: חיובי = מושך להתגוננות, שלילי = מושך לשגרה, והעוצמה 0–1) ו-`s` (רלוונטיות לכל אחד מארבעת המגזרים).
- הציון = ממוצע משוקלל של ה-`lean`, כשמשקל = דירוג² (`src/lib/engine.js`). לכל מגזר יש גם הטיית בסיס (חינוך והתקהלויות מחמירים יותר, משק חיוני מקל יותר – בהתאם למדיניות מ-07/03/2026).
- **המשקלים הם הצעה התחלתית ולא מבוססי נתונים.** יש לכייל אותם עם אנשי המקצוע לפני שימוש אמיתי.
- ארבעת מדרגי המד תואמים למדרגי המדיניות במסמך: פעילות מלאה / חלקית / מצומצמת / הכרחית.

## מבנה
```
server/index.cjs         פרוקסי ל-Claude (המפתח נשאר בשרת)
src/data/factors.js      מאגר הנתונים והמשקלים
src/lib/engine.js        חישוב מקומי, מדרגים ומגזרים
src/lib/ai.js            קריאה לשרת + נפילה חזרה לחישוב מקומי
src/screens/*            חמשת המסכים
src/components/*         מד חצי-עיגול ומדחום
```
תכונות טוטם: יעדי מגע גדולים (≥70px), בלי hover, חסימת בחירת טקסט ותפריט הקשר, איפוס אוטומטי אחרי 2 דקות ללא מגע (עם אזהרה של 15 שניות), גופן Heebo מקומי (עובד אופליין).
